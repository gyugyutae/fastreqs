# 팀 업무 검색 서비스 — 유저스토리

버전: 1 | 가상 시연 데이터

## US-001 검색
- Who: 팀원
- What: 업무 제목과 본문을 키워드로 검색한다.
- Why: 필요한 업무 정보를 빠르게 찾기 위해서.
- 인수조건:
  - 키워드와 일치하는 업무 목록을 표시한다.
  - 결과가 없으면 결과 없음 메시지를 표시한다.
- 상태: 활성 | 버전: 1

## US-003 CSV 내보내기
- Who: 팀 관리자
- What: 검색한 업무 목록을 CSV 파일로 내려받는다.
- Why: 주간 실적 공유 자료를 만들기 위해서.
- 인수조건: 내려받은 파일은 현재 검색 결과의 업무 ID, 제목, 생성일을 포함한다.
- 상태: 활성 | 버전: 1
## US-004 월간 보고서 다운로드
- Who: 팀 관리자
- What: 월을 선택하여 해당 월의 업무 총 건수와 완료 건수가 포함된 CSV 보고서를 다운로드한다
- Why: 월간실적공유시간을 줄이기위해서
- 인수조건:
  - 관리자가 월을 선택할 수 있는 UI를 제공한다
  - 선택한 월의 업무 총 건수와 완료 건수를 계산한다
  - 다운로드된 파일은 CSV이며 열: month, total_tasks, completed_tasks를 포함한다
