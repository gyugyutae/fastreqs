# 팀 업무 검색 서비스 — PRD

버전: 1 | 가상 시연 데이터

## 목표
팀원이 업무 정보를 빠르게 찾고 관리자가 공유 자료를 만들 수 있게 한다.

## 사용자
팀원, 팀 관리자.

## 현재 제품 범위
| Story ID | 기능 | 우선순위 |
|---|---|---|
| US-004 | 월간 보고서 다운로드 — 월을 선택하여 해당 월의 업무 총 건수와 완료 건수가 포함된 CSV 보고서를 다운로드한다 | 보통 |
| US-001 | 업무 키워드 검색 | 높음 |
| US-003 | 관리자 CSV 내보내기 | 보통 |

## 제외 범위
음성 검색, 외부 서비스 연동.

## 성공 조건
검색과 CSV 내보내기 요구사항이 인수조건을 충족한다.
현재 범위는 승인된 유저스토리에 연결해 관리한다.
