# 사용자 흐름

제품 범위는 [PRD](prd.md), 상태/저장 정의는 [data-schema](data-schema.md)를 따른다.

## 1. 시작
운영자가 터미널에서 키·토큰을 로컬 설정하고 채널 링크/ID와 문서 폴더를 입력한다. Slack 접근 및 네 파일/템플릿/ID를 검사한 뒤 연결을 저장한다. 최초 연결로 파일을 수정하지 않는다. 누락/형식 오류는 해결 방법을 안내한다.
재시작은 저장된 입력·후보·질문·연결을 복원하고 최신 파일을 읽는다. 중단 중 대화는 자동 조회하지 않으며 수집 재개 시점을 안내한다.

## 2. 분석 요청: 서로 독립인 두 경로
| 경로 | 트리거 | 분석 자료 |
|---|---|---|
| 일반 채널 | @FastReqs 분석해줘 또는 설정된 종료 키워드(예: 수고하셨습니다) | 직전 성공 분석 이후 수집한 새 대화 + 동일 경로 미결 + 현재 문서 |
| 파일 스레드 | .md 업로드 메시지의 스레드에서 @FastReqs 분석해줘 | 해당 파일 + 해당 스레드 답변 + 동일 파일 미결 + 현재 문서 |

일반 메시지는 저장만 하고 매번 모델을 호출하지 않는다. 첫 채널 분석은 수집 시작 이후부터다. 파일 분석은 채널 대화/분석 경계를 건드리지 않는다. 업로드만으로 분석하지 않는다.
파일은 UTF-8 .md, 메시지당 하나, 최대 1 MB, 비어 있지 않아야 한다. 동일 채널·동일 내용 재업로드는 기존 스레드로 안내한다. 내용 변경은 새 입력이며 이전 파일 미결을 자동 승계하지 않는다. 다른 채널은 독립이다. 합친 입력이 모델 예산을 넘으면 분할 업로드를 요청하며 임의 절삭하지 않는다.

## 3. 후보와 보완
추가/수정/삭제 후보마다 근거·Who/What/Why·인수조건·Story/PRD 전후를 제시한다. 수정/삭제 대상은 현재 활성 Story여야 한다.
필수 정보가 없으면 후보 스레드에서 질문한다. 누구나 답할 수 있고 답변 즉시 해당 후보만 재검토한다. 부족하면 추가 질문, 충돌하면 선택 질문, 충분하면 승인 카드로 진행한다. 양립하는 답은 합칠 수 있으나 최신 발언을 무조건 진실로 취급하지 않는다.
승인 전 자연어 정정/추가 답변은 카드 새 버전을 만들며 이전 버튼을 무효화한다. 승인 후 실제 변경 요청은 새로운 수정 후보로 만든다.

## 4. 개별 결정과 반영
누구나 후보별 승인/거절 가능하며 최초 처리된 결정이 유효하다. Story와 관련 PRD 부분은 한 승인 범위로 보여주고 함께 저장한다. 거절은 문서 불변이다.
승인 시 파일 변경을 감지하면 적용을 중단하고 최신 문서로 새 미리보기를 만들어 재승인받는다. 두 파일 저장 성공 후에만 완료 안내한다. 일부 실패는 복구 시도, 복구 실패는 부분 반영 상태와 대상 파일 안내로 끝낸다.
삭제는 활성 Story/PRD 범위에서 제거하되 내부 이전 내용/근거/처리자를 보존하고 ID를 재사용하지 않는다.

## 5. 기술 문서 영향
Story 승인 후 실제 영향 있는 Spec/ADR 변경을 별도 카드로 제안한다. 미결/거절 시 기존 문서를 유지하고 갱신 검토 필요를 표시한다. ADR은 기록을 덮어쓰지 않고 새 결정/대체 관계를 남긴다.
일반 재분석은 기술 후보를 폐기하지 않는다. 관련 Story의 새 변경이 승인되면 기존 기술 후보를 오래된 것으로 막고 최신 제안을 만든다. 거절 기술 후보는 자동 부활시키지 않는다.

## 6. 이월·동시 요청·실패
승인 완료는 현재 문서로만 참고한다. 보완/충돌/승인 대기는 동일 입력 경로에 이월하고 거절은 제외한다. 새 명시 요구는 거절한 주제를 다시 제안할 수 있다.
재분석 대상의 결정은 잠시 보류: ‘재분석이 끝나면 새 제안을 확인해주세요.’ 성공하면 새 카드로 교체, 실패하면 이전 카드의 유효 상태를 복원한다.
분석 중 새 메시지는 저장하고, 같은 경로의 새 트리거는 후속 요청 하나로 합친다. 현재 분석을 취소하지 않는다. 안내: ‘현재 분석 중입니다. 새 요청은 완료 후 이어서 처리하겠습니다.’
분석 실패는 입력/미결/문서를 유지하며 [다시 분석]을 제공한다. 일시 오류는 자동 재시도 최대 1회, 호출 제한 대기시간을 존중한다. 키/권한/입력 오류는 설정 수정 안내로 처리한다.
