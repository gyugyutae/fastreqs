# FastReqs — 유저스토리

각 FR-US ID는 FastReqs 기능이며 시연 대상 제품의 US-001 등과 구분한다.

## FR-US-001 최초 설정
- Who: 운영자
- What: 터미널에 Slack 채널 링크/ID와 문서 폴더를 입력한다.
- Why: 채널별 문서를 노트북에서 관리하기 위해서.
- 인수조건: 네 파일/템플릿/ID 및 채널 접근을 확인하고 연결 저장. 최초 연결은 파일 수정 없음. 다음 실행에 재사용.

## FR-US-002 대화 기반 분석
- Who: 채널 참여자
- What: 일반 대화 후 멘션 분석 요청 또는 종료 키워드로 분석을 시작한다.
- Why: 매 메시지 분석 없이 회의에서 결정한 변경을 확인하기 위해서.
- 인수조건: 새 대화만 분석, 한 사람 발언으로 후보 가능, 매 메시지 LLM 호출 없음, 오탐이어도 승인 전 파일 불변.

## FR-US-003 회의록 분석
- Who: 채널 참여자
- What: .md를 올리고 업로드 메시지 스레드에서 봇에 분석 요청한다.
- Why: 회의 기록의 요구사항도 같은 승인 흐름으로 반영하기 위해서.
- 인수조건: 파일 하나/UTF-8/1 MB/빈 파일 제외. 일반 채널 대화와 별도. 같은 채널 동일 내용은 기존 스레드 안내. 긴 입력은 분할 업로드 안내, 임의 잘라 분석하지 않음.

## FR-US-004 정보 보완
- Who: 채널 참여자
- What: Who/What/Why 부족 정보에 스레드로 답한다.
- Why: 봇이 목적이나 사용자를 추측하지 않게 하기 위해서.
- 인수조건: 누구나 답변. 답변 즉시 후보만 재검토. 부족하면 추가 질문, 충분하면 카드. 상충하면 사용자에게 선택 질문 및 승인 보류. 승인 후 실제 변경을 요구하는 답은 새 수정 후보.

## FR-US-005 후보 정정
- Who: 채널 참여자
- What: 후보 스레드에서 자연어로 정정하고 새 변경 미리보기를 확인한다.
- Why: 잘못 해석한 내용을 처음부터 다시 입력하지 않고 고치기 위해서.
- 인수조건: 해당 후보만 재검토, 성공 후 카드 교체, 새 승인 전 파일 불변. 변경 전후/근거/인수조건/PRD 영향 표시.

## FR-US-006 Story/PRD 공동 승인
- Who: 채널 참여자
- What: 후보마다 승인·거절한다.
- Why: 승인한 변경만 현재 요구사항과 제품 범위에 반영하기 위해서.
- 인수조건: 누구나 결정 가능, 최초 결정만 적용. 한 승인으로 Story/PRD 부분 변경. 삭제 시 활성 범위에서 제외, 내부 이력/ID 보존. 둘 다 저장돼야 성공 안내.

## FR-US-007 기술 문서 영향
- Who: 채널 참여자
- What: 관련 Spec/ADR 변경 후보를 별도로 승인한다.
- Why: 구현 계약과 결정 이유가 요구사항을 따라가도록 하기 위해서.
- 인수조건: 영향 있을 때만 제안. 미승인/거절은 기존 문서 및 갱신 검토 표시. Story 변경 승인 시 오래된 후보 교체. ADR 기존 결정 근거 보존 및 새 결정/대체 관계.

## FR-US-008 재분석과 이월
- Who: 채널 참여자
- What: 미결 후보를 다음 분석에서 이어서 검토한다.
- Why: 승인하지 못한 변경이 사라지지 않게 하기 위해서.
- 인수조건: 승인 대기/보완만 같은 입력 경로로 이월, 승인 완료는 문서 참고, 거절은 제외. 재분석 중 대상 후보 결정 보류, 성공 시 교체/실패 시 복원. 새 요청은 후속 요청 하나로 병합.

## FR-US-009 상태와 파일 보호
- Who: 운영자 및 채널 참여자
- What: 프로그램을 다시 켜거나 수동 편집/저장 실패 후에도 현재 상태를 확인한다.
- Why: 승인 기록과 최신 문서를 잃거나 덮어쓰지 않기 위해서.
- 인수조건: 저장 상태 복원, 수집 재개 안내, 꺼진 동안 자동 조회 없음. 수동 편집 감지 시 최신 카드 재승인. 공동 저장 실패 시 복구 시도, 복구 실패 사실/파일 안내.

## FR-US-010 분석 오류
- Who: 채널 참여자
- What: 실패 원인을 확인하고 다시 분석한다.
- Why: 회의 내용/후보를 보존하며 데모를 이어가기 위해서.
- 인수조건: 일시적 오류 자동 재시도 최대 1회. 호출 제한 대기 존중, 설정 오류 안내, [다시 분석]. 실패 입력 보존 및 문서 불변, 유료 자동 전환 없음.
