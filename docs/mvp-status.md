# MVP 구현 상태

2026-10-11. 최신 설계 docs/final을 바탕으로 기존 전체 문서 재생성 초안을 교체했다.

구현: 터미널 숨김 자격 입력·채널/폴더 연결, Bolt Socket Mode, 일반 채널/Markdown 파일 입력 분리, 보완·정정 후보 스레드, 개별 결정·이월·후속 요청, Story/PRD 부분 반영, Spec/ADR 별도 승인, 수동 파일 편집 재승인, SQLite 저널·복구, 재시작·단일 프로세스 보호, OpenRouter 무료 JSON 출력·제한 재시도.

실제 저장은 MVP의 SQLite records(kind,id,data) 테이블에서 논리 객체를 JSON으로 저장한다. data-schema의 테이블은 논리 경계이며 모두 별도 SQL 테이블로 분리하지 않았다. 파일 이전/이후 내용은 작업 저널에 보존한다.

기술 영향 검토 상태는 Slack 후보와 status 명령에 표시한다. 미승인 상태 표시만을 위해 Markdown을 바꾸지 않는다. 기술 후보 스레드 정정은 관련 요구사항을 명시적 재분석으로 요청하도록 안내한다. 부분 저장을 재시작에서 발견하면 실제 파일과 저널을 비교하고 복구 필요를 안내하며 불확실한 파일을 자동 덮어쓰지 않는다.

검증: 자동 테스트 25개(앱 20개+하네스 5개), 키 없는 모의 시연, Python 컴파일/CLI 진입 확인. 실제 Slack 연결·첨부 전달·OpenRouter 무료 모델 품질/가용성/지연 및 Windows 네이티브 실행은 리허설 대기. 모의 시연은 실증을 대체하지 않는다.
