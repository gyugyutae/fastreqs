# 팀 업무 검색 서비스 — ADR

가상 시연 데이터. 아래는 데모 대상 제품의 기술 결정이며 FastReqs 구현 자체의 ADR이 아니다.

## ADR-001 — CSV 내보내기를 관리자에게 제한
- 상태: Accepted
- 관련 스토리: US-003
- 배경: 초기에는 관리자가 주간 공유 자료를 만든다.
- 결정: CSV 내보내기는 관리자 권한을 가진 사용자만 허용한다.
- 대안: 모든 팀원에게 허용.
- 결과: 서버에서 내보내기 권한을 검사한다. 사용자 역할 범위가 바뀌면 결정을 재검토한다.

## 변경 원칙
기존 결정의 배경과 이유를 보존한다. 기술 정책 변경을 승인하면 새 ADR을 추가하고 기존 ADR을 Superseded로 연결한다.
