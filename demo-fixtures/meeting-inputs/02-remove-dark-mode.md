# 회의 내용 샘플 — 다크 모드 제외

이 파일은 시연 입력의 내용 초안이다. Slack 파일 업로드 처리 방식은 아직 설계 확정 전이다.

개발자 A: 이번에는 검색과 보고서 기능에 집중하면 좋겠습니다.
개발자 B: 그러면 다크 모드 US-002는 제품 범위에서 제외하죠.
개발자 A: 좋습니다. 다크 모드 요구사항을 삭제하는 것으로 정하겠습니다.
개발자 B: 수고하셨습니다.

## 기대 흐름
Slack 대화로 위 발언을 입력 → 마지막 인사로 분석 시작 → US-002 및 PRD의 다크 모드 범위 삭제 미리보기 → 한 번의 승인으로 함께 반영.
Spec에 다크 모드 계약이 남으므로 별도 제거 후보를 제안하며, 승인하기 전에는 기존 계약과 갱신 필요 상태를 표시한다.
다크 모드 삭제에 직접 연결된 ADR이 초기 문서에 없으므로 ADR은 그대로 유지한다.
